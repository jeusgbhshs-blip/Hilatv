# HP09 regression gates

The default Python suite now includes N7 anchors. Its tests are a package, so
collecting N1 and N7 together no longer imports two unrelated `test_node` files as
one module. Collection is tested with a fresh pytest subprocess, including the
budget and project-draft regressions.

Run the complete suite with:

```sh
make accept-hp09
```

This checks FFmpeg/ffprobe and Chinese Tesseract data, then runs **every default
Python test**. Missing OCR is a failure, not a skipped quality test. Use
`make accept-hp09 PYTHON=/path/to/python` to select an existing environment.
CI installs the media/OCR dependencies and runs
this same target. This target does not install global tools, start Compose, or touch
an existing API/web process.

Every shell acceptance uses `infra/scripts/accept_env.sh`. It sources only the
tracked `.env.example`, forces live and both monetary budgets off, removes inherited
vendor secrets and S3 overrides, and owns fresh project/brand/log/progress paths.
The complete unit/media target additionally disables Redis/MinIO destinations.
A shell canary regression proves a developer `.env` (even one named by `ENV_FILE`)
is never executed. Test collection cannot inherit `PYTEST_ADDOPTS` that omit suites.
Artifacts and JUnit results remain in the printed temporary acceptance directory.

The database CI job additionally enforces the PostgreSQL gate with
`HILATV_REQUIRE_DB=1`, as part of gateway acceptance after migration. These tests
create, migrate, and drop only fresh `hp09_budget_*` databases; the test role needs
`CREATEDB` privileges. They run the actual production T03 and HP03 gateway upgrade
functions through Alembic operations; they do not replace the schema with hand-written
test DDL or require unrelated pgvector business tables. The existing schema CI job
still enforces the complete business migration chain. These tests exercise actual
separate processes/connections for both caps, restart/cross-midnight holds,
transaction rollback, and idempotent/conflicting
settlements. No vendor adapter is invoked. Ordinary offline runs report this
explicit database gate as skipped; required-database CI fails if it cannot run.
Existing application databases and their charge logs are never emptied for tests.

Integration exposed and fixed a real HP03/HP08 boundary error: media cost preflight
must use the normalized output size/duration/resolution, without downloading private
reference objects. The actual provider request still uses the adapter's private
store. This keeps the bound identical to the request and avoids duplicate object
reads. Regressions check both image/video bounds, real image bytes reaching the
provider exactly once, and the absence of those bytes from gateway logs.

A second boundary regression covers lock contention across Shanghai midnight.
Admission now samples its day and timestamp after obtaining the ledger lock. A
request queued on yesterday's clock cannot ignore today's already settled money
when the lock becomes available. The deterministic race uses separate SQLite
connections and a real queued thread; PostgreSQL separately verifies its shared
process lock and retained obligations.

HP04 deliberately rejects a narration-bearing shot with no audio take. Older
fallback and aligned-window fixtures are supplied with explicit test WAV assets
rather than restoring a production silence substitute. Their existing visual,
timing and quality assertions remain in force.

The budget, draft, media, real-audio and logo tests use fake transports/providers
where a vendor response is needed. They verify actual ledger transactions, local
media bytes, decoded sound/pixels, authorization and failure states. They establish
those implementation contracts, not commercial speech or generated-video quality.

Draft save acknowledgements are also recoverable. The same atomic snapshot records
the last save's base/new revision and normalized full-field hash. A repeated PUT
can acknowledge that original save only at exactly `base + 1`, with the same fields
and unchanged saved content. It does not write or increment again. Different fields
or any subsequent revision still conflict, returning the current public snapshot;
owner and tenant checks remain ahead of receipt recovery. Seven regressions cover
lost ACK, normalized retry, changed inputs and later teammate edits.
