# HP02 持久草稿与安全提交

关联审查：F04/F05/F06/F07/F09，以及B04负责人保留。没有改变产品方向或SPEC阈值。

## 修改
- 首页输入触发同一持久草稿，文件字节和未同步正文先留浏览器IndexedDB；已上传素材保留上传编号，失败重试不重新上传全部文件。
- 方案页沿用同一project_id与附件；创建请求有冻结输入及操作编号，丢失创建回执后仍查回同一草稿，新文字再以CAS保存。
- 草稿保存按revision确认。409保留本地输入，不换revision盲覆写。未读到指定项目时禁用提交，不能悄悄创建另一项目代替。
- 输入法组合Enter/229不提交；提交同步防重入。开始生成只引用已保存草稿，服务端持久记录operation/workflow身份。同操作重试查询原任务；未知结果保持submitting而不盲重提。
- 原owner、附件、方案、品牌与分镜选择保留，生成前的已确认失败不改项目。普通草稿和旧空白Agent入口兼容。
- 分镜旁白逐字保留本地草稿，继续之前依次确认全部保存；失败不继续，也不丢剩余文字。恢复发现原稿已改时要求逐镜核对。
- 画布旁白/补充提示词保存真实ShotDesk，逐字本地备份、停顿合批、服务端确认后清除。刷新、保存失败和保存期间继续输入均保留最新内容；布局有独立未确认备份与原revision，冲突不自动重置。
- N6在执行前读取已验证旁白编辑；不把旁白混入视觉提示词，保存本身不启动模型。
