# 导出文件的精确选择

文件选择保存具体 version_id，比例、语种、时长只作为筛选。相同规格的新旧结果可用「导出 1/2…」列表逐份选择；刷新、重排或新增行不会改变当前精确 ID。某份文件暂不可用时明确要求重新选择，不借用另一份导出或母版的预览、元数据和审核批准。

成功导出优先选择响应 exported_version_ids 中匹配本次画幅和语种的结果；旧接口缺此字段时，依次兼容新增 ID、源母版 hash 匹配和最后匹配行。source_key/source_media_hash 仅保留合法 hash 供内部匹配，普通界面不显示。列表轮询早于本次导出的旧响应不能覆盖新回执。导出等待期间母版改变仍回到母版；旧源的后到回执不能把页面自动切回旧导出。旧导出不使用新改稿序号。

另修复分镜时长显示：复用一位小数的显示格式（例如 1.4 秒、4.7 秒），不改原始 duration_s 或时间轴数据。

验证：全量前端 43 项 Node、73 项 Vitest 通过，新增 8 项精确导出用例覆盖同规格结果、指定回执、旧接口兼容、源绑定、缺失 ID、门禁与元数据更新。生产 TypeScript、相关 E2E 的独立严格 TypeScript、限定文件 ESLint、diff 检查通过。浏览器契约新增精确选择/刷新/导出回执、母版批准隔离和等待期间母版更新场景；本轮未运行浏览器 E2E、构建、启停服务或调用真实模型。API exported_version_ids 由协调者后续整合。
