# 生成前比例与时长

首页和方案页复用生成设置芯片与原生模态弹层，沿用 DESIGN token、主题和品牌。比例默认自动，常用项为 16:9、9:16、1:1、4:3，其余 3:4、3:2、2:3、4:5、21:9 收进更多。时长提供自动、15/30/60 秒及 5–180 整数秒自定义。选择立即进入本地持久草稿，并按既有串行自动保存同步。明确设置优先于输入文字，自动保留 null/null 意图；语言和品牌策略仍如实显示未开放。

设置包含在草稿指纹、创建时冻结的请求、CAS 保存、备份、冲突双方比较和未知提交冻结中。旧版已同步本地草稿迁移到自动，不凭空产生一次未保存编辑。正文与设置共同标识方案；设置变化清空旧方案和方向选择，须先保存再重新出方案。方案请求沿用 project_id + draft_revision，服务端读取保存快照，不新增请求设置来源。恢复方案时核对 concept_preview_generation_settings；旧记录缺此元数据只按自动处理。

弹层使用原生 dialog 焦点约束、radio 语义与方向键、ESC 关闭和焦点返回；选项及芯片可点区域至少 44px。自定义输入回车只应用设置，避免触发外层表单生成；合成输入回车不提交。界面不新增模型或费用细节。

验证：全量前端单测 30 项 Node + 71 项 Vitest 通过；其中草稿专项 30 项（新增设置相关 10 项）。TypeScript、限定文件 ESLint 与 diff 检查通过。新增 generation-settings.spec.ts 编写两主题/375px、键盘与焦点、刷新与跨页恢复、改设置后旧方案不可提交、无意外生成的浏览器用例；本轮未启动 Playwright 浏览器或执行浏览器 E2E，未构建、启停原服务或调用真实模型。视觉与实际触屏验收由整合后的 CUA 联调完成。
