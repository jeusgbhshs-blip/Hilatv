# 比例与时长弹层精简

仅调整 GenerationSettingsPicker 与对应浏览器契约。沿用原品牌、主题 token、portal/挂载保护、原生模态、ESC/焦点返回、radio 方向键，以及草稿、显式优先级、校验、回车和 IME 规则，不变更服务端设置或首页创作区。

比例默认自动改为轻量中性行；常用四画幅在桌面四列、手机两列，真实 SVG 形状保留，原生 radio 视觉隐藏但名称明确，选中只用蓝描边与小勾。更多仍用原生 details，所选比例来自其中时自动展开。时长采用四段中性分段控件，自定义默认折叠，已有自定义值或错误时展开。自定义值重开直接聚焦可见数字输入，不创建隐藏的可聚焦自定义 radio。说明压缩，优先级/参考图适配放在选择区后，底部自动保存行为说明与右对齐完成按钮。

CSS 约束：桌面弹层最大宽 480，手机两侧 16 留白（375 宽时目标 343）；常用比例格手机 min-height 64、桌面 80；自动行、时长段、关闭与完成按钮至少 44。桌面 p5、手机 p4，间距只用 token。以上为代码约束与预期值，不冒充浏览器实测；整合后 CUA 记录实际宽高与溢出。

时长未选项悬停只加深文字，避免像第二个选择；选中项用 surface 底和 medium 字重，不借用弹层阴影，键盘焦点环单独保留。
