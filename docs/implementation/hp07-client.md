# HP07 前端生成身份与重试

- 新的节点生成或单镜重生建立新的operation_id；同一次网络/用户重试保留原ID和原输入，不用换ID伪装新结果。
- 生成失败后提供“重试上次提交”，仅当前项目/当前页面；结果未知时保留原提交，按照服务端原因继续等待，不另发一次收费生成。
- 每个节点的生成点击同步防重入；原始404不再转为另一条legacy重跑路径。
- 服务端重放旧成功结果时，不用旧canvas.layout_version覆盖更新的编辑，重新读取当前画布，并保留本地未确认正文/位置。
- 整片Agent对现代草稿先按revision保存必要输入与完整附件/品牌/方案，再提交同一operation；未知结果与当前已提交任务复用身份。拒绝拿新增文字冒充已提交原任务。
- 项目视图显式按project_id隔离组件实例；旧请求完成不能改写另一个项目界面。提交中同步锁定Agent输入，错误保留本地输入备份。

验收：28 Node＋45 Vitest、TypeScript、ESLint通过，含新nonce、显式旧nonce、旧结果不覆盖、404不转跑、现代草稿保存后提交及unknown重试同身份。后台幂等/跨进程/费用回归由HP07后端212835d覆盖。完整持久任务中心与跨设备未知任务恢复仍属HP12，未以当前页面重试入口冒充完成。
